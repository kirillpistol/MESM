MESM — запуск на Windows
=============================

Что нужно:
1. Windows 10/11.
2. Python 3.11 или новее.
3. Интернет при первом запуске — Python скачает необходимые библиотеки.

Быстрый запуск:
1. Распакуйте архив MESM_Windows.zip в обычную папку, например:
   C:\MESM

2. Откройте папку MESM.

3. Дважды щёлкните:
   START_MESM.bat

4. Первый запуск может занять несколько минут:
   - создаётся .venv;
   - устанавливается Streamlit;
   - пересобирается Fiscal Reference Panel;
   - выполняется структурная проверка.

5. После запуска браузер откроет интерфейс MESM.
   Обычно адрес:
   http://localhost:8501

Как остановить:
Вернитесь в чёрное окно MESM и нажмите Ctrl+C.

Как проверить сборку:
После первого запуска можно открыть:
CHECK_MESM.bat

Он выполняет:
- пересборку Fiscal Reference Panel;
- pytest;
- validate_project.py.

Важно:
- реальные банковские данные в эту сборку не входят;
- dashboard показывает текущий публичный Reference Layer;
- ReferenceScore пока не откалиброван, поэтому интерфейс не придумывает состояние NORMAL/WARNING.

Если START_MESM.bat пишет, что Python не найден:
переустановите Python и отметьте пункт "Add Python to PATH".

Обновление официального бюджета:
После первого успешного запуска можно дважды щёлкнуть UPDATE_OFFICIAL_DATA.bat.
Он скачает официальный комплект Сургута с admsurgut.ru, сохранит raw-файлы локально,
запишет URL и SHA-256 в data\manifest\source_manifest.csv и пересоберет processed CSV.
Существующий офлайн-snapshot не удаляется, если официальный сайт недоступен.
