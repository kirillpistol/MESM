MESM — запуск на Windows
=============================

Что нужно:
1. Windows 10/11.
2. Python 3.11 или новее (при установке отметьте "Add Python to PATH").
3. Интернет при ПЕРВОМ запуске — Python скачает библиотеки. Дальше интернет
   нужен только для необязательного обновления официальных данных.

Быстрый запуск:
1. Распакуйте архив MESM_Windows.zip в обычную папку, например C:\MESM.
2. Откройте папку MESM и дважды щёлкните START_MESM.bat.
3. Первый запуск занимает несколько минут: создаётся .venv, ставятся
   библиотеки, пересобирается Fiscal Reference Panel, выполняются быстрые
   проверки.
4. Откроется браузер с интерфейсом MESM. Адрес обычно http://127.0.0.1:8501;
   если порт занят, программа сама выберет следующий свободный (8502, 8503...),
   точный адрес написан в чёрном окне.

Как остановить: вернитесь в чёрное окно и нажмите Ctrl+C.

Если установка оборвалась (например, пропал интернет): просто запустите
START_MESM.bat ещё раз — установка повторится автоматически. Если вы заменили
файлы проекта на новую версию, недостающие библиотеки доустановятся сами.

Данные и источники (важно для показа)
-------------------------------------
Проект работает на СОХРАНЁННОМ СНИМКЕ данных: папки data\processed,
data\reference, data\external. Интернет и работоспособность сайта
администрации во время показа не нужны.

- Целостность снимка. Файл data\manifest\snapshot_manifest.csv хранит SHA-256
  каждого файла снимка. START_MESM.bat сверяет файлы с манифестом и пишет
  ВНИМАНИЕ, если что-то изменено или удалено. CHECK_MESM.bat в этом случае
  завершается ошибкой.
- Обновление официальных данных (необязательно, лучше НЕ запускать перед
  показом): UPDATE_OFFICIAL_DATA.bat.
    * Сайт недоступен или страница изменилась — ничего не меняется, проект
      продолжает работать на прежнем снимке.
    * Сайт ответил, но новая сборка не прошла проверки (например, парсер
      вытащил заметно меньше строк) — прежний снимок восстанавливается.
    * Всё прошло — обновляются таблицы и манифест снимка; URL и SHA-256
      скачанных файлов пишутся в data\manifest\source_manifest.csv.
- Экран «Источники» показывает статус CONFIGURED, пока обновление не
  запускалось: исходные файлы в архив не входят, а в нём лежит только
  обработанный снимок.

Как проверить сборку:
CHECK_MESM.bat — полная проверка (целостность снимка, пересборка панели,
pytest, структура проекта). Может занять несколько минут.

Важно:
- реальные банковские данные в эту сборку не входят;
- dashboard показывает текущий публичный Reference Layer;
- ReferenceScore пока не откалиброван, поэтому интерфейс не придумывает
  состояние NORMAL/WARNING.
