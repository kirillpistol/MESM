# MESM: данные, категории и уровни

## 1. Основной объект

- Муниципалитет: **Сургут**
- ОКТМО: **71876000**
- Региональная обучающая сетка: ХМАО — Югра
- Основная частота: месяц

## 2. СберИндекс: потребительские расходы

В текущем исходном наборе используются шесть категорий:

| Код MESM | Категория СберИндекса | Роль |
|---|---|---|
| ALL | Все категории | основной целевой ряд |
| FOOD | Продовольствие | структура базового спроса |
| HEALTH | Здоровье | медицинские и аптечные расходы |
| DINING | Общественное питание | потребительская активность вне дома |
| MARKETPLACES | Маркетплейсы | онлайн-торговля |
| TRANSPORT | Транспорт | транспортные расходы |

Исходный период текущего файла: январь 2023 — декабрь 2024.

## 3. Идентификатор территории

Основной ключ:

```text
ОКТМО + период + категория
```

Название муниципалитета не используется как основной join-key между источниками.

Для Сургута:

```text
ОКТМО = 71876000
```

## 4. Слои данных

### RAW

Оригинальный файл источника без изменения.

Назначение:

- аудит;
- воспроизводимость;
- SHA-256;
- возможность повторной обработки.

### CANONICAL

Минимальный нормализованный набор:

- ОКТМО;
- название территории;
- период;
- категория;
- значение;
- источник;
- статус идентичности.

### FEATURES

Только признаки, используемые моделью:

- lag 1/2/3/6/12;
- rolling mean 3/6;
- rolling std 3/6;
- календарь;
- относительные изменения;
- внешние показатели после подключения.

## 5. Внешние данные, которые планируется подключать

### Муниципальный уровень — Сургут

- бюджет;
- исполнение бюджета;
- бюджетная обеспеченность;
- локальные события/новости;
- погода;
- доступные показатели городской экономики.

### Региональный уровень — ХМАО

- средняя заработная плата;
- структура занятости;
- отраслевой профиль;
- мобильность;
- региональные экономические показатели;
- при необходимости показатели соседних муниципалитетов.

### Федеральный уровень — только когда экономически обосновано

- ключевая ставка;
- инфляция / CPI;
- курс рубля;
- нефть;
- общероссийские календарные и регуляторные факторы.

Федеральные показатели не собираются «для количества». Каждый новый признак должен иметь понятный экономический канал влияния и проверяться по OOS-метрикам.

## 6. Мобильность

Мобильность рассматривается как потенциальный опережающий признак потребительской активности.

Принцип:

```text
мобильность_t или mobility_(t-1) → прогноз расходов_(t+1)
```

Конкретный лаг выбирается только после проверки без утечки данных.

## 7. Погода

Предварительный набор:

- средняя температура;
- аномалия температуры;
- осадки;
- снег;
- экстремально холодные/тёплые дни.

Погодные данные особенно могут быть полезны для транспорта, общественного питания и отдельных сезонных категорий.

## 8. Новости и события

Используется дата публикации. Информация после момента прогнозирования не может попасть в признаки.

Планируемые агрегаты:

- число экономически значимых новостей;
- тип события;
- локальность: Сургут / ХМАО / федеральный уровень;
- потенциальная сила события;
- лаг 1–4 периода.

## 9. Правило включения нового источника

Источник включается в модель только если одновременно выполняются три условия:

1. понятен экономический механизм;
2. информация доступна на момент прогноза;
3. на временном тесте она улучшает MAE или качество детектора.

Иначе источник остаётся только в Reference Layer или исключается.

## 10. Что уточнить у администрации

- какие муниципальные данные доступны ежемесячно;
- какие данные считаются официальным оперативным индикатором;
- какие показатели доступны по Сургуту, а какие только по ХМАО;
- какие категории расходов администрации наиболее полезны;
- какие показатели допустимо использовать как внешние признаки;
- есть ли внутренние временные ряды, которые можно подключить без публикации исходных данных;
- какие даты публикации необходимо учитывать для исключения look-ahead bias.
