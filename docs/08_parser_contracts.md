# Контракты парсеров

В MESM нет одного «универсального Excel-парсера». Dispatcher выбирает контракт для конкретного семейства источников.

Основные семейства: исполнение бюджета, консолидированное исполнение МО, перспективный финансовый план, расходные обязательства, межбюджетные трансферты, бюджетная обеспеченность, статья 136, оценка качества бюджета, сопоставление бюджетной классификации и методические таблицы трансфертов.

Контракт парсера использует имя файла как подсказку, но не как единственный критерий. Дополнительно проверяются ключевые слова в листах и содержимом, обязательные смысловые колонки, aliases и правила периода/версии.

Старый `.xls` обрабатывается отдельным проверенным read-only backend. `.xlsm` читается только как таблица — макросы не исполняются.
