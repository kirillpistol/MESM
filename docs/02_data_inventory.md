# Инвентаризация данных

Собранного пакета уже достаточно, чтобы строить Fiscal Reference Dataset и проверять парсеры на реальных источниках.

| Семейство | Что есть | Для чего используется |
|---|---|---|
| Исполнение бюджета | 2022–2025 | план / уточнение / факт, доходы, расходы, трансферты |
| Промежуточное исполнение МО | полугодовые и as-of срезы | состояние бюджета внутри года |
| Перспективный финансовый план | 2026–2031 + версия на 01.07.2026 | официальный прогноз и его изменение |
| Расходные обязательства | текущий и плановый период | структура обязательств |
| Межбюджетные трансферты | МО × форма × период | зависимость от трансфертов и структура финансирования |
| Бюджетная классификация | несколько периодов | защита от ложных structural break из-за смены кодов |
| Статья 136 БК РФ | многолетние расчеты и классификация | режим бюджетных ограничений |
| Качество управления финансами | 2024–2025 | официальные формулы и муниципальные входные показатели |
| Методические документы | 2023–2028 | семантика кодов и правила источников |

Автоматически сформированные реестры лежат в `data/manifest/source_manifest.csv` и `data/manifest/archive_inventory.csv`.

Главный пробел — высокочастотные муниципальные потребительские данные. Для части старых `.xls` также нужен отдельный проверенный read-only backend. Эти ограничения не блокируют разработку Fiscal Reference слоя.
