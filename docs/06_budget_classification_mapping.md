# Сопоставление бюджетной классификации

Изменение бюджетных кодов может выглядеть как экономический structural break, если сравнивать периоды напрямую. Поэтому перед change-point detection коды приводятся к устойчивой сущности.

Поддерживаются типы связей `one_to_one`, `one_to_many`, `many_to_one`, `renamed_same_code`, `newly_introduced`, `retired`, `excluded`.

Для mapping сохраняются версия источника, период действия и основание. Fuzzy matching может предложить кандидата, но неоднозначное соответствие не подтверждается автоматически.
