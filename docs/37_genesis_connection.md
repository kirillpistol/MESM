# MESM 1.12.1 → PISTOL GENESIS

Связаны четыре репозитория: MESM, pistol-genesis-ai (ядро), genesis-level-2 (финансовый расчёт), genesis-level-3 (адаптер источника). Код и данные разделены. Ядро не скачивает алгоритмы по сети.

## Общая локальная сборка для Windows
Распакуйте папки рядом: MESM, pistol-genesis-ai, genesis-level-2, genesis-level-3. Из MESM сначала START_MESM.bat (окружение), затем START_MESM_GENESIS.bat. Новый процесс запускает локальный MESM API и отдельное ядро с явно подключённым mesm_budget. Результат: data/genesis/MESM_GENESIS_results.json и MESM_report.html. Серверы живут до закрытия окна/Ctrl+C. Это локальный режим тестирования, без mTLS, только 127.0.0.1. Существующие защищённые workers и их политики не меняются. Если 8080 или 8765 занят, процесс остановится; закройте ранее запущенный API либо задайте другие порты через аргументы connect_genesis.py. Файлы результатов и временные токены не публикуются в Git.

Не открывайте локальное ядро во внешнюю сеть. Общая сборка не устанавливает сертификаты и не требует OpenSSL для локального режима. Данные передаются один раз при старте; нет автоматического опроса, повторов задач, дедупликации или обучения. Повторный запуск создаёт новое ядро; доставка в существующий worker увеличивает его агрегаты повторно.

## Существующее защищённое ядро
Установите обновлённые L2/L3 рядом с ядром. Добавьте пути трёх репозиториев в PYTHONPATH. Запустите новый совместимый финансовый worker с доверенным локальным модулем:

`python -m level1_core.server --port 8443 --tls-config <server.json> --algorithm-module level2_algorithms.mesm_budget`

Control-клиентом (level1_core.discovery.client_from) подключите `/v1/algorithms/attach`, body: `{"api_version":"1.0","name":"mesm_budget"}`. Data-клиенту запрещено подключать алгоритмы. Задайте MESM_API_TOKEN своего работающего MESM API и запустите из уровня 3:

`python -m level3_data.run_mesm --mesm http://127.0.0.1:8765 --core https://localhost:8443 --client-config <data.json> --municipality Сургут --output <local-output-directory>`

Конфигурация клиента должна allowlist-ить точный endpoint и pin сертификата. На удалённом сервере MESM API должен находиться локально к адаптеру; его HTTP-token не отправляется через открытую внешнюю сеть. Нужны действующие ваши сертификаты; локальные тестовые сертификаты из examples нельзя применять как production PKI.

Strict binding worker отклоняет legacy /v1/tasks. Для такого режима необходимы вручную утверждённые passport, manifest и связка mesm.plan/1, подготовленная через существующий BoundAdapter/сервер частей. Эта интеграция не снимает strict policy и не подключается автоматически к существующей строгой связке. PACKAGE_SPECS финансового модуля включает SHA-256 исходников для будущего утверждения. В общей сборке запускается отдельный явно локальный worker.

## Что умеет финансовый модуль
Вход mesm.plan/1: муниципалитет, год, стадия ADOPTED/PLAN_PERIOD, единица thousand_rub, доходы, расходы, финансирование, URL, публикация, snapshot_id, статус official_public. Суммы берутся из API budget_official_plan, фильтр по городу точный. Синтетика и неподтверждённые пользовательские импорты отклоняются.

D = expenditure − revenue; G = max(D − financing, 0). При численном шуме до 1e-12 от масштаба отрицательно несущественная разность признаётся нулём. Результат содержит исходный источник, период, snapshot_id, D/G и явные early_warning_proven=false, legal_compliance_proven=false. Нулевой G означает арифметическое покрытие плана, не исполнение и не юридический вывод. Статус official_public — декларация каталога, не дополнительная независимая сверка источника.

В состоянии остаются только count и сумма непокрытой плановой потребности обработанных записей; это технический агрегат по доставкам, не сводный дефицит города. Исходные строки/HTML не сохраняются в ядре. Общий отчёт скачивается адаптером и сохраняется у потребителя отдельно от 64 KiB task-контракта ядра. Нельзя передавать большой HTML одной задачей.

## Проверка
С PYTHONPATH на четыре репозитория (у MESM — src):

`python genesis-level-3/mesm_e2e.py --mesm-root MESM`

Проверка создаёт временные тестовые сертификаты, запускает настоящий MESM API и настоящее mTLS-ядро, передаёт реальные публичные плановые суммы, сверяет 2025, скачивает отчёт, проверяет неизвестный муниципалитет и роли. Для неё нужен openssl. Windows .bat отдельно проверяется на вашем ПК. После этого можно изучать прогнозирование: текущее GENESIS ещё не обучает модель и не делает самостоятельный экономический вывод вне этих формул.
