# Обработанные данные

В репозитории лежат только те публичные извлечения, которые нужны для воспроизводимых примеров и тестов. Полные промежуточные выгрузки можно хранить локально и пересобирать отдельно — так репозиторий остается компактным.

Дополнительные публичные извлечения и manifest можно добавлять в GitHub только если они нужны для воспроизводимости конкретного теста.

Некоторые Excel используют defined names и конструкции, которые сторонний движок может показать как `#NAME?`. MESM не зависит от пересчета workbook: сохраняются исходные показатели, а поддерживаемые формулы пересчитываются отдельно в Python.
