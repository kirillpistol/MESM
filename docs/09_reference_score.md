# Fiscal Reference Score

Reference-контур сначала рассматривается как набор интерпретируемых признаков, а уже потом как единый score.

Кандидаты: величина бюджетного уточнения, execution gap, структура и зависимость от трансфертов, покрытие обязательств, динамика бюджетной обеспеченности, долговая нагрузка, режим статьи 136, отдельные официальные показатели качества и причины уточнений.

Финальные веса пока не фиксируются. Это сделано специально, чтобы не получить «магический score», выбранный после просмотра результатов. Веса или supervised-модель должны калиброваться только на development-периоде.
