# Границы проекта

MESM создается как система поддержки решений, а не как автоматический механизм бюджетных или кредитных решений.

У проекта два контура. **Reference / Fiscal** использует официальные бюджетные данные: планирование, уточнения, исполнение, трансферты, расходные обязательства, бюджетную обеспеченность, ограничения по статье 136 БК РФ и другие публичные показатели. **Predictive / Observed** использует более частые сигналы: потребительскую активность, топливо, цены, доходы, транспорт, занятость и разрешенные агрегированные банковские показатели.

Сейчас в первую очередь строится Reference / Fiscal слой, потому что собранного публичного пакета ХМАО уже достаточно для воспроизводимого ingestion, нормализации, проверки и исторического сравнения.

## Исследовательский вопрос

Может ли двухконтурная модель, которая объединяет официальное муниципальное бюджетное состояние и более частые потребительские/экономические сигналы, обнаруживать устойчивые структурные изменения раньше традиционной отчетности при приемлемом числе ложных тревог и измеримой практической ценности?

## Что не является целью

MESM не подменяет официальную бюджетную методологию, не называет собственные расчеты «официальной бюджетной обеспеченностью», не переводит новую модель в production автоматически, не принимает индивидуальные кредитные решения и не хранит защищенные банковские данные в публичном репозитории.
