# Безопасность

## Граница публичного репозитория

В репозиторий нельзя добавлять секреты, персональные данные, сырые банковские транзакции, номера счетов, идентификаторы клиентов и закрытые банковские выгрузки.

## Загрузка источников

Макросы не исполняются. Архивы проверяются на path traversal. Тип файла определяется по содержимому, а не только по расширению. Неизвестная структура отправляется в quarantine. Raw-файлы считаются неизменяемыми и идентифицируются по SHA-256.

## Доступ

Базовый принцип — `DENY BY DEFAULT`. Роль пользователя сама по себе не должна давать доступ ко всем строкам и колонкам. В банковском контуре доступ должен учитывать dataset, поля и цель использования.

## Модель

Для рабочей модели сохраняются artifact, схема признаков, hash обучающих данных, метрики, Git commit и rollback target. Низкая уверенность или конфликт детекторов не должны автоматически запускать действие.
