# MESM — L3: открытое техническое рассмотрение

Автор: Kirill Pistol. Версия приложения: 1.14.0. Дата комплекта: 06.10.2026.

MESM — самостоятельный муниципальный аналитический источник L3: панель, расчёты, общий отчёт и API. GENESIS подключается как отдельный потребитель. Этот комплект подготовлен для рассмотрения проекта, в том числе в Сбербанке. Он не означает одобрение, внедрение или разработку по заказу Сбербанка.

## Как запустить

Распаковать всю папку MESM. Windows 10/11, Python 3.11+ и интернет для первой установки зависимостей. Открыть START_MESM.bat; остановка — Ctrl+C в окне запуска. Подробности: README_WINDOWS.txt. Это комплект исходного кода, не автономный EXE; библиотеки устанавливаются отдельно. В Windows эта конкретная сборка не запускалась.

START_MESM_L3.bat запускает API отдельно. Локальный токен выводится оператору; не отправлять его в публичные материалы. Для разных серверов обязательны HTTPS и настройка сертификатов по docs/38_l3_manager_architecture.md. Сервер API не запускает GENESIS. Внешний менеджер GENESIS не входит в этот ZIP.

## Последовательность проверки

1. Открыть docs/38_l3_manager_architecture.md и docs/adr/0001-mesm-as-independent-l3.md: границы приложения, запуск, завершение циклов.
2. Проверить перечень данных: docs/36_data_inventory.md, docs/MESM_Data_Requirements_1.12.0.docx и config/data_products.json. Версия Word указана в имени; актуальные функции описаны в документах текущего кода.
3. Сверить источники: config/external_sources.json, config/official_sources.json, docs/29_source_evidence_register.md. Статус connected не равен validated.
4. Проверить конкретные плановые значения по data/evidence/decision713.pdf и data/manifest/report_trace_2025.json. Не все исторические числа имеют полную трассировку до ячейки; ограничение не скрывается.
5. Пройти формулы: docs/30_function_reference.md, config/formula_registry.json, docs/31_cash_schema_and_audit.md. Пять формул серверной выдачи — часть алгоритмов. Показатели плана и факта, первоначальный и уточнённый план, реальные и синтетические данные различаются.
6. Открыть панель: бюджет, кассовый контур, монитор шоков, источники, справочник поиска. Скачать общий отчёт кнопкой сверху справа; сопоставить исходные значения, подстановки, результаты и пределы вывода.
7. Проверить код по docs/40_current_code_index.md. Выполнить `python -m pip install -e ".[dashboard,dev,yaml,research,changepoint,excel]"`, затем `python -m pytest -q`. Пропущенные проверки требуют отдельного прочтения причин, а не считаются успешными.
8. Проверить передачу данных и методики: docs/35_data_access_and_replication.md, docs/39_methodology_and_updates.md; API /v1/catalog, /v1/report-package, /v1/methodology. Повторяемость чисел не означает одинаковый generated_at или идентификатор сессии.
9. Для другого города: scripts/init_municipality.py и инструкция переноса. Нужны собственные источники и проверки; нельзя переносить числа Сургута как факты другого города.

## Что можно утверждать

| Часть | Состояние и предел вывода |
| --- | --- |
| Панель, отчёт, исходники, формулы, API | Доступны для проверки; документация описывает реализацию |
| Публичный бюджетный снимок | Включён; сверять документ, единицу, год и вид плана |
| Кассовая нормализация | Реализована; демонстрационные файлы не являются реальным месячным исполнением |
| ФНС 5-НДФЛ | Сохранён годовой источник; не заменяет месячный Predictive, требует отдельной сверки |
| Детекторы и FPR | Контрольные сценарии и синтетические результаты; не доказанный эффект внедрения |
| Раннее предупреждение на реальном Reference | Не подтверждено; нет согласованного месячного ряда и исторических дат доступности |
| Непокрытая плановая потребность = 0 | Арифметическая увязка плана; не доказательство фактического поступления средств или юридического соответствия |
| Справочник поиска | Ручные требования, подтверждение и экспорт запроса работают; ИИ-адаптеры и управляемые парсеры — следующий этап |
| Человеческие подтверждения | Имя вводится оператором; это журнал, не электронная подпись |
| Источники и доказательства | Полнота различается; отсутствие ссылки/ячейки не заменяется вымышленной проверкой |

## Прозрачность и права

В комплект входят исходный код, публичный и демонстрационный снимок, конфигурации, документация и тесты. Локальные базы оператора, личные импорты, токены, ключи, сертификаты и виртуальная среда не включаются. Документы сторонних источников сохраняют свои права; публичная доступность не означает свободную лицензию. В репозитории нет отдельной лицензии на распространение кода: возможность технического рассмотрения не задаёт условия коммерческого использования. Такие условия согласуются с автором отдельно.

Зависимости в pyproject.toml заданы преимущественно нижними границами версий. Полной фиксации окружения для любой будущей установки пока нет. RELEASE_ENVIRONMENT.txt фиксирует среду проверки этой сборки; SHA256SUMS.json фиксирует байты комплекта, а не истинность данных.

Проект периодически обновляется проверенными версиями. Следующий этап автора — контролируемый поиск источников через другие ИИ и парсеры с повторной человеческой сверкой: docs/41_manual_search_directory.md.
